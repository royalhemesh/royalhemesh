### 📊 Bank Marketing Profit Optimisation
> **Business Problem:** A bank's direct marketing campaigns were generating high outreach volume but poor conversion rates, with significant budget going toward customers unlikely to convert.

**Stack:** `Python` · `Pandas` · `Scikit-learn` · `SQL` · `Matplotlib`

- Cleaned and preprocessed a **41K-record dataset** with significant class imbalance using resampling and cost-sensitive learning
- Applied **hypothesis testing** to validate all preprocessing assumptions before model tuning
- Optimised campaign targeting with probability thresholds and cost-benefit analysis
- Achieved **ROC-AUC of 0.93**, reducing unnecessary outreach by **40–45%**
- Fed root-cause findings from failed interactions back into the feature engineering pipeline

### 📦 Retail Demand Forecasting
> **Business Problem:** An inventory team was working off inaccurate demand signals due to dirty transactional data — irregular gaps, zero-demand weeks, and inconsistent formatting were all skewing forecasts.

**Stack:** `SQL` · `PostgreSQL` · `Python`

- Built a preprocessing layer to clean and normalise transactional data before any forecasting logic ran
- Implemented **rolling average models in SQL** that reduced forecast error (MAE) by **15–25%** versus baseline
- Delivered a reliable weekly inventory signal with no added infrastructure overhead
